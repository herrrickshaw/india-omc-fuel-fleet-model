- Cumulative benefit: $6-8bn import reduction + $2-3bn export growth = $8-11bn gross impact

```
SCENARIO DEFINITIONS:

OPTIMISTIC (60% Substitution):
├─ All major capex on-time (BPCL AP + RIL commissioned by FY30)
├─ Private sector adds 0.8 MMTPA ahead of schedule
├─ BHAVYA parks attract 25+ downstream processors
├─ Trade pattern: Domestic feedstock preferred (cost + logistics)
├─ FY30 import reduction: $12.3 bn/year
├─ Domestic premium: 3-5% (declining)
├─ Net national benefit: $11.5 bn/year by FY30
└─ Outcome: Textile industry cost-competitive vs Bangladesh (2-3% edge)

BASE CASE (50% Substitution):
├─ 80% capex execution (minor delays, 6-12 month slippage)
├─ Private sector capacity slower (0.6 MMTPA instead of 0.8)
├─ BHAVYA parks attract 15-20 processors
├─ Phased adoption by fabric industry
├─ FY30 import reduction: $10.2 bn/year
├─ Domestic premium: 5-8% (startup costs)
├─ Net national benefit: $8.5 bn/year by FY30
└─ Outcome: Textile cost parity with Vietnam achieved

PESSIMISTIC (30% Substitution):
├─ Significant capex delays (BPCL AP slips to FY31)
├─ RIL O2C scaled back or reprioritized
├─ BHAVYA parks delay land acquisition
├─ Fabric industry slow to adopt domestic feedstocks
├─ FY30 import reduction: $6.1 bn/year
├─ Domestic premium: 8-12% (sustained high cost)
├─ Net national benefit: $3.5 bn/year by FY30
└─ Outcome: Gap narrowing but insufficient for cost leadership

COST IMPACT TO TEXTILE INDUSTRY:

                    Optimistic    Base Case    Pessimistic
FY28 Cost Change    -1.5%         -0.8%        -0.2%
FY30 Cost Change    -3.2%         -2.1%        -0.6%
Export Volume Gain  +8-12%        +4-6%        +1-2%
Competitiveness     Bangladesh    Vietnam      Indonesia

PROBABILITY WEIGHTS (Expert Assessment):
├─ Optimistic (60% sub): 25% probability
├─ Base Case (50% sub): 50% probability
├─ Pessimistic (30% sub): 25% probability
└─ Expected value: 47% substitution by FY30 ($9.6bn import reduction)
```

**Interpretation**:
- Base case (50%) is most likely; aligns with typical Indian capex execution
- Downside risk: BPCL AP delays = significant impact (affects 40% of potential reduction)
- Upside potential: All systems execute + private sector enthusiasm = Bangladesh cost parity
- Hedging strategy: Bio-feedstock pathway + specialty chemical BHAVYA parks reduce capex dependency
