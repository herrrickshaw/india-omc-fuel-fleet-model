From petrol to product — India's petrochemical import tree

The polymers and chemicals India imports are made from the same petrol-range refinery streams it burns or exports as fuel: naphtha (→ olefins) and reformate aromatics (→ BTX). Each product below is tagged with its 8-digit ITC-HS code and import dependence — the map for crude-to-chemicals import substitution.

How to use this. Every card is a building block traceable to a petrol-range stream; each product carries the ITC-HS code to pull live tonnage, value and origin on Tradestat (tradestat.commerce.gov.in) or Niryat. The deepest, highest-value gaps — polycarbonate, MDI/TDI, nylon, ABS/ACN, styrene — cluster in the benzene/propylene chains: engineering plastics & polyurethanes, ~85–100% imported. As ethanol/EV free petrol-range volume, cracking it into these products captures the petrochemical premium (Digital Refining: +$1.5–2/bbl marginal, $60–80/bbl full COTC) and erases an import.
