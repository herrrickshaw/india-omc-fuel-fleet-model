# Textile petrochemicals — closing the fuel-to-chemicals loop into man-made fibre

The petrol→petrochemicals pivot in this repo (ethanol/EV cap petrol demand → free naphtha + reformate →
route to chemicals instead of the fuel "red ocean") has a **specific, high-value landing zone: man-made
fibre (MMF)**. India's fibre basket is cotton-skewed while the world runs ~70–75% MMF (Textile Exchange
2024: synthetics 69% + cellulosics 6%); India both imports the **MMF polymer feedstock** below *and*
runs a **technical-textile deficit** concentrated in MMF-intensive segments (NTTM/DGCIS FY24: Mobiltech
−$351M tyre-cord/airbag, Hometech −$111M nonwovens, Specialty fibres +275% imports). Every fibre polymer
here starts from the **same petrol-range streams India burns as fuel** — so the fibres are the loop's
natural close.

## The loop, one line
**Ethanol displaces petrol → freed naphtha (steam cracker → ethylene/propylene/C4) + freed reformate
(reformer + aromatics complex → PX/benzene) → MMF polymers → domestic polyester/acrylic/nylon/spandex/
PP-PE fibre → flips both the MMF-import gap and the technical-textile deficit.**

\* PP and HDPE are dual-use (packaging + fibre); only the fibre/nonwoven grade is textile-attributable — treat these as *shared*, not fully textile.

**Cellulosic exception:** **viscose / lyocell / modal (MMCF)** and their feedstock (dissolving-grade wood
pulp) are **not** petrochemical — they don't ride the naphtha loop. India's MMCF (~16% of its MMF) stays
a pulp/agri-fibre story, not a fuel-to-chemicals one. Keep them out of this table.

## Sizing the textile slice of the substitution prize
- **Core fibre-only petrochemicals** (polyester PTA+MEG, acrylic ACN, nylon caprolactam, spandex BDO):
  **≈ ₹38,000 cr (~$4.4 bn/yr)** of import that fuel-freed feedstock could substitute — before counting
  the fibre-grade share of PP/PE.
- **Polyester alone (PTA+PX+PFY+MEG ≈ ₹30,000 cr)** is the biggest single textile cluster and maps exactly
  onto the **reformer→PAREX/ISOMAR** aromatics route — the unit that today makes petrol octane.
- **The specialty-fibre close:** ACN → **PAN → carbon fibre**, and nylon/high-tenacity yarn, are precisely
  the NTTM **Specialty-fibres (+275% imports)** and **Mobiltech (−$351M)** deficits — the propylene and
  benzene chains feed them, so the loop reaches the hardest import gaps, not just commodity fibre.

**(B) the finished MMF/technical-textile import layer** that virgin domestic polymer would then feed.

## Why this completes the loop (ties back to the textile analysis)
1. **Demand side (fuel):** E20 ≈ 10.8 bn L, E30 ≈ 16 bn L of petrol displaced (sibling models) → frees
   naphtha/reformate.
2. **Conversion:** naphtha cracker (olefins: MEG, PP, PE, ACN, BDO) + reformer/aromatics complex
   (aromatics: PX→PTA, benzene→caprolactam) — see `naphtha_to_chemicals_pivot.md`, `naphtha_btx_routes.md`.
3. **Fibre:** those polymers ARE the MMF building blocks → domestic polyester/acrylic/nylon/spandex/PP-PE.
4. **Textile outcome:** substitutes the **MMF feedstock import** *and* the **technical-textile deficit**
   (Mobiltech tyre cord = nylon/polyester; Hometech nonwovens = PP; specialty = PAN/carbon fibre) — and
   supplies virgin polymer that **recycled-polyester (rPET)** then supplements downstream. Fuel → chemicals
   → fibre → (recycle) → fibre: the loop is closed.

## Policy anchor — National Fibre Mission 2030-31 (Ministry of Textiles)

The loop is not a proposal — it is the Mission's stated intent. Key figures from the **National Fibre
Mission 2030-31 Concept Note** (MoT, Dec 2025):

| Metric | Figure | Read |
|---|---|---|
| MMF contribution to economy | **₹13,61,300 cr (₹13.6 L cr)**, 2024-25 | scale of the synthetic value chain |
| MMF production | **75 → 130 lakh MT** by 2030-31 (CAGR 9.6%) | rises from 62.5 (FY20) → 75 (FY24) lakh MT (CAGR 4.66%) |
| Global rank / share | **2 → 1**; production share **10% → 14.6%** | China alone >70% of global MMF output |
| **MMF imports** | **24.1 → 31.5 lakh MT** by 2030-31 (CAGR 4.0%) | up from 18.04 lakh MT FY20 — the substitution prize |
| Non-cellulosic MMF imports | **1.37 → 1.88 lakh MT** (FY21→FY25) → 2.76 by 2030-31 | "reliance on specialised fibres & functionalised polymers" |
| PLI for Textiles | **₹10,683 cr outlay** | "**focuses on downstream** MMF fabrics & apparel" |

**Why it validates this loop (Mission's own words):**
- *"Incentivise **local MMF feedstock production through sustainable chemical pathways and recycled raw
  material use**."*
- *"…promoting **recycled MMF production** and incentivising **investment in advanced petrochemical value
  chains**."*
- Specialty fibres (**aramid, carbon fibre, glass, PBO, PTFE**) — *"very limited indigenous production…
  most are imported"* → matches the ACN→PAN→carbon-fibre and specialty-fibre deficit above.

**The gap this loop fills:** PLI covers **downstream** fabric/apparel; the **upstream feedstock**
(MEG, PX, ACN, caprolactam, BDO) is exactly what ethanol-freed naphtha/reformate would supply — the
part the current incentive structure leaves open.

## Caveats
- **FY25 segment breakdown:** Ministry of Textiles has published only headline aggregate ($2.92 bn) and top 2 segments (Packtech 37.5%, Indutech 28%). 
  **Official HSN code mapping is now available** (Export-Import Bank of India, page 63), allowing direct [TradeStat](https://tradestat.commerce.gov.in/) queries for each 
  segment's FY25 export/import data. See "[HSN codes by segment](#hsn-codes-by-segment)" above for query codes. Remaining 10 segments in the table above 
  use 15% growth scaling (conservative baseline) pending analyst pull from TradeStat.
- HSN codes are indicative 8-digit ITC-HS (fibres/polymers in Ch 39/54/55, monomers in Ch 29); verify exact
  subheading + current-year value on Tradestat/DGFT before citing.
- Import values are approximate (DCPC/DGCIS FY24-25 basis, ₹→$ at ₹86); PP/PE are shared with packaging.
- Volume figures: ACN 164 kt (IndexBox, 2023) and caprolactam ~150 kt (MoC&I, 2022) are hard; MEG is
  industry-range (falling post-Paradip Mar-2024); BDO is derived; PX/PTA India is broadly net-long (RIL).
- Substitution needs the downstream units (cracker, aromatics complex, ACN/caprolactam/MDI plants), not just
  freed feedstock — this is a feedstock-availability + import-gap map, not a project plan.
